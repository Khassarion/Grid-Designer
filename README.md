# Grid Designer

브라우저에서 이미지를 격자·중첩 레이아웃으로 배치하고 **PNG**로 내보내는 정적 웹 에디터입니다.  
서버·설치·빌드 없이 `index.html`만 열면 동작합니다.

**사용:** [https://ainukehere.github.io/Grid-Designer](https://ainukehere.github.io/Grid-Designer)

**튜토리얼 (후원 이미지 벽지):** [tutorial.html](tutorial.html) · [배포본](https://ainukehere.github.io/Grid-Designer/tutorial.html)

## 사용법

위 페이지에서 바로 쓰거나, 저장소의 `index.html`을 브라우저로 열면 됩니다.
후원 이미지로 OBS 벽지를 만드는 순서는 [튜토리얼](tutorial.html)을 보세요.

앱바에서 **한국어 / English**를 선택할 수 있습니다 (기본: 한국어).

### 개념

| 대상 | 역할 |
|------|------|
| **캔버스** | 최상위 컨테이너. 격자 없음. 크기 = 내보내는 PNG 해상도 |
| **레이아웃** | 격자 배치 단위. 패딩·셀·스페이싱·시작 코너/축·자식 정렬·제약 설정 |

- 캔버스 아래에는 레이아웃·이미지를 자유롭게 둡니다.
- 레이아웃 안에는 이미지·하위 레이아웃을 격자로 둡니다.
- 하위 레이아웃(레이아웃의 자식)은 **크기 입력이 잠기고**, 격자 재배치 시 부모 **셀 크기**에 맞춰집니다. 내부는 스케일하지 않고 **1:1**로 그립니다.
- 레이아웃보다 큰 셀 그룹은 잘리지 않고 **오버플로**로 밖으로 나옵니다.

### 레이아웃 설정

| 항목 | 설명 | 기본 |
|------|------|------|
| 패딩 | 좌/우/상/하 | 0 |
| 셀 크기 | 고정 px. 이미지는 셀에 꽉 채움 (`object-fit: fill`) | 200×160 |
| 스페이싱 | 셀 간격 X/Y (음수 가능, 겹침) | 0 |
| 시작 코너 | Left/Right × Top/Bottom | Left Top |
| 시작 축 | 수평 / 수직 | 수평 |
| 자식 정렬 | 셀 **그룹**이 레이아웃 안 어디에 붙는지 (9점). 이미지→셀 정렬 아님 | Left Top |
| 제약 | 자동 / 열 개수 / 행 개수 | 자동 |
| 배경 | 색(RGB) + 불투명도(0–100). 0이면 완전 투명 | 투명 |

**크기 프리셋**

- 캔버스: `3840×2160` · `2560×1440` · `1920×1080`
- 레이아웃(캔버스 직하위): `200×1080` · `1920×160` · `400×1080`
- 부모 셀에 크기가 잠긴 하위 레이아웃에서는 프리셋 숨김

### 격자 재배치

다음일 때 레이아웃 자식이 격자에 다시 맞춰집니다.

- 자식 추가 / 제거 / 전체 삭제
- 하위 레이아웃 삭제(부모 레이아웃 쪽)
- 레이아웃 설정 변경 (패딩·셀·스페이싱·배치·정렬·제약 등)
- 레이아웃 **크기** 변경 (입력·프리셋·미리보기 리사이즈 — **드래그 중에도 실시간**)

### 미리보기 조작

| 대상 | 클릭·이동·리사이즈 |
|------|-------------------|
| 캔버스 직속 이미지 | 가능 |
| 모든 레이아웃 프레임 | 가능 |
| 레이아웃 안의 이미지 | 불가 |

- **자석**: 레이아웃 이동·크기 조절 시 다른 레이아웃 가장자리·부모 경계·중앙에 스냅 (기본 ON)
- 휠로 확대/축소, 미리보기 레이아웃에 이미지 드롭으로 추가
- 계층 구조에 레이아웃과 이미지가 함께 표시됩니다 (형제 간 드래그로 순서 변경)
- 이미지는 `Ctrl+클릭`으로 다중 선택, `Shift+클릭`으로 같은 부모 아래 연속 선택 후 미리보기로 드래그해 일괄 이동
- **추가 ▾ → 자동 설정** — 감시 폴더에 새 이미지가 생기면 지정 레이아웃에 자동 추가 (Chrome/Edge, 탭이 열린 동안). 설정·사용 여부는 브라우저에 저장(기본 OFF). 사용 중이면 추가 버튼에 작은 `auto` 표시, 메뉴에 ON 표시
- 레이아웃 이름 더블클릭으로 이름 변경
- 계층 구조 **추가** 메뉴: 이미지 추가 · 레이아웃 추가
- 선택 항목이 없으면 **제거** 비활성화
- `Delete`로 선택 항목 제거, `Ctrl+Z`로 실행 취소
- `Ctrl+C` / `Ctrl+V`로 레이아웃(하위 포함) 또는 이미지 복사·붙여넣기
- `Ctrl+D`로 선택 항목 바로 아래(형제)로 복제
- `Ctrl+S`로 PNG 내보내기, `Ctrl+Shift+S`로 구조 저장

### 구조 저장·불러오기

- **저장** — 캔버스·레이아웃·배치를 JSON으로 다운로드
- **이미지 포함** 체크 시 이미지도 JSON에 함께 저장 (기본 체크)
- **열기** — JSON으로 복원 (다른 브라우저·PC에서도 동일). 기존 작업은 덮어씀
- 이미지 없이 저장하면 레이아웃 구조만 남고, 이미지 슬롯은 저장되지 않습니다

### PNG 내보내기

- **내보내기**로 현재 캔버스를 PNG로 저장
- **자동 내보내기**를 켜면 구조 변경 시 PNG를 자동 저장 (PNG 위치가 지정된 경우에만, 미리보기 크기 조절·숫자 입력은 끝난 뒤에만). 기본 켜짐
- (지원 브라우저) 저장 위치를 고정해 두고 같은 파일에 덮어쓰기 가능

### 사용 흐름 예

1. 미리보기 상단에서 캔버스 해상도 설정
2. **+ 하위**로 레이아웃 추가 → 크기·셀·패딩 등 설정
3. 레이아웃에 이미지 추가 (또는 드롭)
4. 필요하면 하위 레이아웃을 더 중첩
5. 미리보기에서 위치·크기를 드래그로 조정
6. 필요 시 **구조 저장**으로 백업
7. **PNG 저장**
