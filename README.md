# OBS Grid Layout

OBS에서 이미지들을 그리드로 배치하는 정적 웹 디자이너입니다.

로컬 이미지를 배치한 뒤 **PNG**로 내보내 OBS 이미지 소스로 추가합니다.

---

## 사용법

`web/index.html`을 브라우저로 열면 됩니다. **로컬 웹 서버 불필요**.

### 개념

| 대상 | 역할 |
|------|------|
| **캔버스** | OBS 장면처럼 자식만 두는 컨테이너. 격자 없음. 크기 = PNG 해상도 |
| **레이아웃** | 격자 배치 단위. 패딩·셀·스페이싱·시작 코너/축·자식 정렬·제약 설정 |

- 캔버스 아래에는 레이아웃·이미지를 자유롭게 둡니다.
- 레이아웃 안에는 이미지·하위 레이아웃을 격자로 둡니다.
- 하위 레이아웃(레이아웃의 자식)은 **크기 입력이 비활성화**되고, 격자 재배치 시 부모 **셀 크기**로 맞춰집니다. 내부 콘텐츠는 스케일하지 않고 **1:1**로 그립니다 (찌그러짐 없음).
- 레이아웃보다 큰 셀 그룹은 잘리지 않고 **오버플로**로 밖으로 나옵니다.

### 레이아웃 설정

| 항목 | 설명 | 기본 |
|------|------|------|
| 패딩 | 좌/우/상/하 | 0 |
| 셀 크기 | 고정 px. 이미지는 셀에 꽉 채움 (`object-fit: fill`) | 200×160 |
| 스페이싱 | 셀 간격 X/Y (음수 가능, 겹침) | 0 |
| 시작 코너 | Left/Right × Top/Bottom | Left Top |
| 시작 축 | 수평 / 수직 | 수평 |
| 자식 정렬 | 셀 **그룹**이 레이아웃 안 어디에 붙는지 (9점). 이미지→셀 정렬 아님 | Left Top |
| 제약 | 자동 / 열 개수 / 행 개수 | 자동 |

**크기 프리셋**

- 캔버스: `1920×1080` · `1280×720` · `1080×1920`
- 레이아웃(캔버스 직하위): `200×1080` · `1920×160` · `400×1080`
- 부모 셀에 크기가 잠긴 하위 레이아웃에서는 프리셋 숨김

### 격자 재배치 (`reflow`)

다음일 때 레이아웃 자식 위치가 격자에 다시 맞춰집니다.

- **격자** 버튼
- 자식 추가 / 제거 / 전체 삭제
- 하위 레이아웃 삭제(부모 레이아웃 쪽)
- 레이아웃 설정 변경 (패딩·셀·스페이싱·배치·정렬·제약 등)
- 레이아웃 **크기** 변경 (입력·프리셋·미리보기 리사이즈 후)

캔버스에는 격자가 없으므로 **격자** 버튼은 비활성화됩니다.

### 미리보기 조작

| 대상 | 클릭·이동·리사이즈 |
|------|-------------------|
| 캔버스 직속 이미지 | 가능 |
| 모든 레이아웃 프레임 | 가능 (어느 레이아웃을 사이드바에서 골라도 동일) |
| 레이아웃 안의 이미지 | 불가 |

- 사이드바 선택과 무관하게, 위 규칙으로 미리보기에서 항상 조작합니다.
- **자석** 버튼(미리보기 상단): 레이아웃 이동·크기 조절 시 다른 레이아웃 가장자리·부모 경계·중앙에 스냅. 토글 가능 (기본 ON).
- 휠로 확대/축소, 미리보기·자식 목록에 이미지 드롭으로 추가.

### 구조 저장·불러오기

- **구조 저장** → 캔버스·레이아웃 설정·자식 배치·이미지를 담은 JSON 다운로드
- **구조 불러오기** → JSON을 열어 다른 브라우저에서도 동일하게 복원 (기존 작업은 덮어씀)

### 내보내기

- **PNG 저장** → OBS **이미지 소스**로 사용
- (지원 브라우저) 저장 위치 고정 후 덮어쓰기

### 사용 흐름 예

1. 캔버스 해상도 설정 (예: 1920×1080)
2. **+ 하위**로 레이아웃 추가 → 크기 프리셋 또는 직접 입력
3. 레이아웃 선택 → 셀/패딩/스페이싱 등 설정 → 이미지 추가
4. 필요하면 레이아웃 안에 또 하위 레이아웃 추가
5. 미리보기에서 레이아웃 위치를 드래그로 조정 (자석 ON 권장)
6. 필요 시 **구조 저장**으로 백업 · 다른 PC/브라우저에서 **구조 불러오기**
7. PNG 저장 → OBS에 이미지 소스로 추가
